\subsection*{AI use statement}
Generative AI tools were used in preparing this work and we take full
responsibility for its final content. Specifically: (i)~AI assistance was used
for writing and editing the manuscript text, and for authoring and refactoring
experiment code; (ii)~an earlier draft's bibliography was generated with LLM
assistance and was found to contain fabricated co-author names and incorrect
venues --- every entry has since been re-verified against its authoritative
record (DOI, arXiv, or publisher metadata) using an automated citation-retrieval
tool, and the verification script is released with the code; (iii)~all
experimental results reported here were produced by executed code against real
model outputs, not generated by an AI tool, and all numbers in the text were
checked against the emitted result files. AI tools were not used to generate
data, results, or findings.

\subsection*{Reproducibility statement}
All experiments run against open-weight models served locally via Ollama, with
fixed claim sets and fixed elicitation-question banks; no closed-model API is
required to reproduce the central result (EXP-R1, §\ref{sec:r1_faithful}).
The protocol, the full 16-question elicitation bank, condition prompts, and
answer-parsing rules are given in Appendix~\ref{app:r1_faithful}; claim
construction is in Appendix~\ref{app:claims}; the interrogation pipeline is
specified in Appendix~\ref{app:adage_details}; and the regex patterns for the
label-free rule are in Appendix~\ref{app:regex_patterns}. Codebase, raw
transcripts, per-trial result files, and a table-reproduction script will be
released publicly.
